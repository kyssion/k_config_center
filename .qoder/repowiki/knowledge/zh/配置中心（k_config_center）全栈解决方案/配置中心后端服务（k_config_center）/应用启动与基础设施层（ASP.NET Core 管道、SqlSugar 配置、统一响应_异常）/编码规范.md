- 对外 JSON 响应统一通过 `ApiResponse.Ok/Fail` 返回 `{ code, message, data }` 结构，HTTP 状态码固定为 200，业务失败由 `ErrorCode` 分段枚举表达。
- 业务侧校验失败抛出 `BusinessException(ErrorCode, message)`，由 Program 中的全局异常中间件统一捕获并转为统一响应，避免在各 Controller 重复处理。
- 错误码集中在 `ErrorCodes` 枚举并按段划分（0/10000+/20000+/30000+），新增错误码只能追加且禁止修改既有值。
- 数据库访问统一通过 DI 注入 `ISqlSugarClient` 单例，禁止 Repository 自行 new，以保证跨 Repository 的环境事务（`DatabaseTransactionRunner`）生效。
- 所有含 `DeletedAt` 的实体默认启用全局软删除过滤，需要读取已删除记录时通过 `ClearFilter` 临时绕过。
- 写操作审计所需的操作人与来源 IP 通过 `OperationHelper` 从 `HttpRequest` 提取（`X-Operator` 头缺省为 `system`），Service 层仅传递字符串给 Repository。

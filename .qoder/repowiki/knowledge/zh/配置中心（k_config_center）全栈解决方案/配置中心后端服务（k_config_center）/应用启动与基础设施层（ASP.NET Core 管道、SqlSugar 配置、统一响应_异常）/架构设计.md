模块由两部分组成：
- `Program.cs` 作为应用入口，使用 `WebApplication.CreateBuilder` 构建管线，按顺序注册控制器、SqlSugar 客户端、`IHttpContextAccessor`、各 Repository 与 Service（均为 Scoped），并通过中间件链实现全局异常处理（将 `BusinessException` 转为 HTTP 200 + `{code,message,data}` 统一响应）、开发环境 Swagger UI、HTTPS 重定向、静态资源托管以及 `/api/{*path}` 与 SPA `index.html` 双 fallback。
- `src/Infrastructure/` 提供横切能力：`SqlSugarSetup` 以单例方式注册 `ISqlSugarClient`，连接 PostgreSQL，启用实体特性映射（DbFirst）并对所有含 `DeletedAt` 的实体注册全局软删除过滤器；`ApiResponse`、`BusinessException`、`ErrorCodes` 共同构成后端方案 7.1 的统一响应契约——HTTP 一律 200，业务错误通过分段枚举码（0/10000+/20000+/30000+）表达；`OperationHelper` 封装 MD5、操作人/IP 提取及 PostgreSQL 唯一约束冲突识别；`SwaggerOperatorHeaderFilter` 通过 `IOperationFilter` 为所有非 GET 接口自动注入 `X-Operator` 请求头说明。
依赖方向单向：`Program.cs` 引用 Infrastructure 与上层 Services/Repositories，Infrastructure 不反向依赖业务层，仅暴露纯工具与数据访问初始化能力。

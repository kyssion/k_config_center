- Controller 方法统一返回 Task<object> 并通过 ApiResponse.Ok(...) 包装 Service 返回值，保持响应格式一致。
- Service 构造函数通过依赖注入获取各 Repository 与 IHttpContextAccessor，从中提取 Request 用于获取操作人与客户端 IP。
- Repository 对外的数据形态使用 Domain/ 下的 record（ConfigurationData、ConfigurationVersionData 等），Entity 仅在 Repository 内部转换，禁止 Entity 泄漏到 Service 或 Controller。
- 异常统一通过抛出 BusinessException(ErrorCode.Xxx, message) 表达业务错误，由全局异常中间件转换为 HTTP 响应。
- 发布/回滚等跨表写操作通过 DatabaseTransactionRunner.ExecuteAsync 包裹委托执行，Service 不直接持有 ISqlSugarClient。
- 列表与详情查询使用 SqlSugar 的 LeftJoin 显式带上 deleted_at == null 条件，避免依赖全局过滤器在联表中的行为。
- md5 一律由 OperationHelper.ComputeMd5 在服务端计算后写入，不在请求中信任前端传入的哈希值。

项目采用经典的 Controller → Service → Repository → Entity 四层结构：Controllers 仅负责 HTTP 契约，Services 编排业务逻辑（如 PublishService 封装事务型发布），Repositories 通过 SqlSugar 访问数据库，Entities 映射表结构；Infrastructure 提供统一的 ApiResponse、BusinessException、ErrorCodes、SqlSugarSetup 以及 SwaggerOperatorHeaderFilter 等横切能力，由 Program.cs 在启动时集中注册 DI。核心配置管理（core_configuration）与基础设施/宿主（infrastructure_and_hosting）两个子模块分别对应业务层与横切层，二者通过共享的 Models（Domain/Requests/Responses）、Entities 与 Infrastructure 类型进行解耦协作，对外统一以 REST API 形式暴露。

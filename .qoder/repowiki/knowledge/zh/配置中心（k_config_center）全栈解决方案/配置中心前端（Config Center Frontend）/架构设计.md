以 `src/main.tsx` 为应用入口，`App.tsx` 挂载全局主题与路由，`router/index.tsx` 按 namespace/group/environment/configuration/audit 等维度注册页面路由，所有页面统一嵌套在 `layouts/MainLayout.tsx` 提供的侧边栏+顶栏+内容区壳中。业务页面（configuration_page）仅负责数据展示与交互，复用 shared_ui 中的通用组件（PageContainer、DiffViewer、ColumnSettingButton 等）与 hooks（useTableRequest、usePolling），并通过 `api/` 下按领域划分的模块（configuration.ts、namespace.ts、group.ts 等）调用后端 HTTP 接口；`store/` 目录预留全局状态扩展点。前后端契约集中在 `api/types.ts` 的 TypeScript 类型定义中，由页面与 API 层共同遵守。

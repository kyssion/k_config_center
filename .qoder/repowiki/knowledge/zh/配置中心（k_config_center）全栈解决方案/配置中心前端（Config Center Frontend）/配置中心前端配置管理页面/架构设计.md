模块以 React 组件为入口，按功能拆分为四个页面文件：`ConfigurationList.tsx` 负责命名空间/环境/配置组三级级联筛选与配置项表格；`ConfigurationEditor.tsx` 基于 `@monaco-editor/react` 实现多格式内容编辑、草稿保存与发布；`VersionHistory.tsx` 展示分页版本列表并支持双版本 Diff 与回滚；`ConfigurationDetailDrawer.tsx` 作为只读详情抽屉被列表复用。API 层集中在 `web/src/api/configuration.ts`，统一通过 `request` 调用 `/api/configurations/*` 路由，覆盖 CRUD、publish、rollback、offline、versions 等后端接口；`web/src/api/operationLog.ts` 提供独立的 `/api/operation-logs` 日志查询。页面依赖共享的 `@/components`（如 `StatusTag`、`FormatTag`、`DimensionCell`、`FormDrawer`、`DiffViewer`）与 `@/hooks`（`useTableRequest`、`useColumnSettings`、`usePolling`），并通过 `@/utils/formatters` 注册表对 json/yaml/xml/properties/toml 进行语法校验与格式化，形成「页面 → 组件/hook → API → HTTP 拦截器」的单向依赖。

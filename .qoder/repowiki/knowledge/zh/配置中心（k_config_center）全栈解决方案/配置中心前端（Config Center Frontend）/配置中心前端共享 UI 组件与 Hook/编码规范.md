- 组件采用默认导出函数式组件 + 独立 interface Props 定义 props 的类型契约
- Hook 返回对象解构多个状态与方法（如 { data, loading, reload }、{ mergedColumns, components, settings, columnMetas, setVisible, setWidth, reset }），调用方按需选取
- 对外暴露的格式能力通过接口（如 ContentFormatter）+ 注册表（Record<string, T>）模式扩展新类型，新增格式只需追加条目而不改动分发逻辑
- 异步请求统一在 Hook 内处理 loading 与错误提示分离（错误由 http 拦截器负责，Hook 仅 finally 收尾 loading），并通过 requestIdRef 防止旧请求覆盖新数据
- 用户偏好类状态（列设置）优先从 localStorage 初始化，写入失败静默降级为仅内存态，保证功能可用性
- 高频交互场景（如拖拽调宽）将中间态更新与落盘持久化拆分为两个回调（onColumnResize / onColumnResizeEnd），避免频繁写 localStorage

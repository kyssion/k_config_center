模块按职责划分为三个并列子目录：`components/` 存放无业务逻辑的纯展示型 React 组件（如 `PageContainer` 统一页面标题+卡片布局、`FormDrawer` 带未保存确认的右侧抽屉表单、`DiffViewer` 基于 react-diff-viewer-continued 的行级差异对比、`ResizableHeaderCell` 实现 antd Table 表头拖拽调宽）；`hooks/` 封装跨页面复用的状态逻辑，包括 `useTableRequest`（loading/data/reload 三件套并防竞态）、`useColumnSettings`（基于 localStorage 持久化列显隐与宽度，配合 ResizableHeaderCell 注入 onHeaderCell）、`usePolling`（定时轮询 Hook）；`utils/` 提供纯函数工具，其中 `formatters.ts` 通过 `ContentFormatter` 接口以注册表形式集中管理 json/yaml/xml/properties/toml/text 的校验与美化能力，`clipboard.ts` 封装 navigator.clipboard 与 execCommand 降级复制。依赖方向单向：hooks 可引用 components（如 useColumnSettings 引用 ResizableHeaderCell），utils 不被其他两者反向依赖，整体构成面向页面的共享基础层。

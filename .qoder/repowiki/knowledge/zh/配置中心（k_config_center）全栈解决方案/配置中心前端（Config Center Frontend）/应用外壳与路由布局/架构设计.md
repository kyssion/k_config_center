模块由四层组成：`main.tsx` 作为应用入口，使用 `ReactDOM.createRoot` 挂载根组件，并通过 AntD 的 `ConfigProvider` 注入中文 locale 与品牌主题（主色 #2f54eb、浅灰画布底色等）；`App.tsx` 仅承载 `<RouterProvider>`，将路由实例从 `@/router` 注入；`router/index.tsx` 通过 `createBrowserRouter` 集中声明所有路由，以 `MainLayout` 为父路由，子路由映射到各业务页面（namespace/environment/group/configuration/audit），并将 `/configuration/:id/edit`、`/configuration/:id/versions` 等嵌套路由挂载在同一布局下；`layouts/MainLayout.tsx` 基于 AntD Layout 实现三栏结构（Sider 导航 + Header 标题与操作人输入 + Content 中的 `<Outlet />`），通过 `useLocation` 高亮当前菜单项，并使用 `localStorage('operator')` 持久化操作人身份以便 HTTP 拦截器注入 X-Operator 头。依赖方向单向：main → App → router → layouts → pages，本模块不直接依赖业务页面内部逻辑。

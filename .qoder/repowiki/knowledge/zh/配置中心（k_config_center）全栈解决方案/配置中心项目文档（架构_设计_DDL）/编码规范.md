- 所有主资源表（namespace/environment/configuration_group/configuration）统一采用 `deleted_at TIMESTAMPTZ` 软删除 + `WHERE deleted_at IS NULL` 的部分唯一索引，保证删除后可复用业务 key。
- 时间戳由数据库层维护：`created_at` 使用 `DEFAULT now()`，`updated_at` 通过统一的 `function_automatic_update_updated_at()` 触发器在 BEFORE UPDATE 时自动刷新，应用层不手动赋值。
- 枚举型字段使用 `VARCHAR(16) + CHECK (...)` 而非 PostgreSQL ENUM，便于扩展新值且避免 ALTER TYPE 带来的迁移成本。
- 历史快照类表（configuration_version、operation_log）不设 `deleted_at` 与删除能力，仅记录 ID 无外键约束，确保审计不可篡改且不拖累主表写入。
- 高频读取路径通过冗余列（如 configuration 中冗余 namespace_id/environment_id）避免多表 JOIN，并以复合查询索引（如 `index_configuration_namespace_environment`）支撑过滤。

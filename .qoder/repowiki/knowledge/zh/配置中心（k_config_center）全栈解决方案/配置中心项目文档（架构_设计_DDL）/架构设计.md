文档按职责划分为三个子目录：`技术方案/` 存放工程级规划（`项目整体架构设计.md` 描述 ASP.NET Core Web API + React SPA 单进程部署、管理端与客户端接口分层、Vite 开发代理与 `wwwroot` 静态托管策略；`前端方案.md` / `后端方案.md` 分别细化两端选型与实现约定）；`设计文档/配置中心设计文档.md` 定义领域模型（namespace → environment → configuration_group → configuration → configuration_version）、ER 关系、状态机（DRAFT/PUBLISHED/OFFLINE 及软删除）、版本发布/回滚流程与变更探测机制；`数据库脚本/配置中心建表脚本.sql` 提供 PostgreSQL 14+ 的 6 张表 DDL，含部分唯一索引（配合软删除）、CHECK 约束、延迟外键、通用 `updated_at` 触发器函数以及默认 `public` 命名空间初始化数据。文档之间通过相对路径互相引用，形成“总体架构 → 详细设计 → 可执行 DDL”的单向依赖链。

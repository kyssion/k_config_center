### 命名空间
- 定义：配置中心的顶层隔离单元（config_center_namespace），用于按业务线或团队划分配置空间，namespace_key 全局唯一且默认内置 public。
- 别名：namespace

### 环境
- 定义：隶属于命名空间的运行环境维度（config_center_environment），如 dev/test/staging/prod，environment_key 在同一 namespace 内唯一。
- 别名：environment、env

### 配置组
- 定义：环境下的配置分组（config_center_configuration_group），类似 Nacos 的 Group / Apollo 的 Namespace 文件，group_key 在同一 environment 内唯一。
- 别名：configuration_group、group

### 配置项
- 定义：配置组内的具体配置条目（config_center_configuration），由 configuration_key + content 组成，content 支持 text/json/yaml/properties/xml/toml 六种格式，而非简单的 key-value 对。
- 别名：configuration、key-value

### 版本快照
- 定义：每次发布/回滚/导入等操作写入 config_center_configuration_version 的一条不可变记录，version_number 线性递增，change_type 限定 CREATE/UPDATE/DELETE/ROLLBACK/IMPORT，本身不提供删除能力。
- 别名：configuration_version、version

### 操作日志
- 定义：config_center_operation_log 表记录的审计日志，仅存维度 ID 不建立外键，operation 字段记录 CREATE/UPDATE/PUBLISH/ROLLBACK/OFFLINE/DELETE 等操作类型，detail 为 JSONB 详情，operator 来自 X-Operator 请求头。
- 别名：operation_log、audit log

### 软删除
- 定义：四类主资源（namespace/environment/group/configuration）统一通过 deleted_at 标记软删除，配合 WHERE deleted_at IS NULL 的部分唯一索引实现同 key 可复用；版本表与审计日志不设 deleted_at，不可删除。
- 别名：soft delete、deleted_at

### 发布状态机
- 定义：配置项的状态流转：DRAFT → PUBLISHED ⇄ OFFLINE，客户端只读 PUBLISHED；"有未发布变更"通过当前 md5 与生效版本 md5 对比判断。
- 别名：status、draft、published、offline

### X-Operator
- 定义：操作人标识来源，阶段一无用户体系，服务端从 HTTP 请求头 X-Operator 读取操作人，缺省值为 system；Portal 侧 http.ts 拦截器自动注入 localStorage 中的操作人，缺省 portal。
- 别名：operator、操作人

### 错误码分段
- 定义：后端 ErrorCode 枚举将错误码按语义分段：10000+ 通用错误、20000+ 基础维度错误、30000+ 配置与发布错误，全部通过 BusinessException/ApiResponse 统一返回，HTTP 仍为 200。
- 别名：ErrorCode、错误码
